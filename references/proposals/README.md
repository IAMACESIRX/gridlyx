# Supplied Build Proposals

These files preserve the exact build/workflow text supplied during platform design. They are **historical input**, not the canonical build files.

The canonical template retains the newer MDK structure (`net.neoforged.moddev` 2.0.144 and `neoForge { version = ... }`). The manually declared NeoForge/LWJGL proposal is kept for provenance and comparison because directly forcing runtime libraries can conflict with Minecraft's dependency graph.
