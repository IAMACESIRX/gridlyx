# Project glossary

- **UAL** — Unified Abstraction Layer: neutral operations above target loader/game adapters.
- **Polyloader** — loader-neutral compatibility architecture spanning prelaunch transformation and top-down sideload/emulation paths.
- **Capability negotiation** — explicit classification of whether a feature is live-safe, emulated, prelaunch/restart-required, unsupported or target-specific.
- **Advanced source set** — isolated Java mechanisms for bytecode, native, GPU, IPC, networking and shared creator-runtime infrastructure.
- **Deep integration** — escalation beyond normal APIs into JVM/native/bootstrap/binary-patch/project-owned engine components while preserving provenance and rollback.
- **Derived runtime** — a verified runtime produced from a known upstream base plus a recorded patch/overlay/capability graph.
- **Section delta** — revisioned change to a 16x16x16 world section calculated away from the authoritative live mutation path.
- **Dynamic Event and Structure Matrix** — trigger-driven runtime structure/environment event system sharing the transactional world-edit pipeline.
- **Virtual registry** — project-owned dynamic definition layer used when native Minecraft registries are too static for restartless authoring.
- **VFSB / bridge protocol** — existing neutral Java/native/Bedrock frame transport terminology. This identifier is subject to the pending project rebrand/migration plan.
- **R0-R6** — project readiness scale from idea through release-candidate evidence.
- **Evidence drift** — documentation/readiness remaining optimistic after the evidence supporting it is stale or invalid.
- **Context pack** — bounded task-specific AI retrieval output generated from the deterministic repository index.
- **Content lock** — exact resolved instance dependency/provenance record.
- **Creator runtime** — in-game/editor-side world, asset, model, scripting, physics, AI and live-development systems.
- **Production runtime** — replay, animation, camera, timeline, capture and export systems.
