# Community

This project is an experimental cross-edition Minecraft engineering platform under active development and rebrand. It spans launcher/runtime management, loader compatibility, live creator tooling, world editing, scripting/native extensions, multiplayer authoring, Bedrock adaptation and machinima/production.

## Evidence-first rule

A feature being described in an architecture document does not mean it is release-ready. The repository uses R0-R6 readiness and target-specific validation. Community-facing statements should link to concrete evidence where practical and should distinguish planned, framework, tested and target-validated work.

## Scope preservation

The canonical conversation-derived requirements are preserved in `docs/CHAT_REQUIREMENTS_TRACEABILITY.md` and `platform/chat-requirements.json`. Contributors should not silently remove or materially weaken those requirements. Scope changes require an explicit project decision and corresponding planning updates.
