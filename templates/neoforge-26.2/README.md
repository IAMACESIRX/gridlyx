# NeoForge 26.2 AI Mod Template

This live template is based on the supplied NeoForge 26.2 ModDevGradle MDK. It is copied by `tools/new_mod.py` to create isolated AI/human mod workspaces.

Canonical versions are locked at repository root in `platform/versions.json`.

For the upstream MDK installation notes and licence, see `references/upstream/mdk-26.2/` and `TEMPLATE_LICENSE.txt`.
